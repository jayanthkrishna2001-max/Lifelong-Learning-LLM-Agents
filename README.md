# Lifelong Learning LLM-Based Agent - Demo

## Run
1. Install Python 3.10+.
2. Open terminal in this folder.
3. Run:
   pip install -r requirements.txt
4. Run:
   python app.py
5. Open http://127.0.0.1:5000

Admin:
username: admin
password: admin123

Features:
- Admin training
- TF-IDF + Chi-Square feature selection
- Logistic Regression, Multinomial Naive Bayes, Linear SVM, Random Forest
- Accuracy, Precision, Recall and F1 metrics
- File-based Q&A for TXT/PDF/DOCX
- Interaction memory
- Feedback storage / continuous-adaptation demonstration

Important:
This is a runnable academic demonstration of the architecture described in the supplied report. It is not a full production LLM implementation. To use a real LLM, connect an approved API or local model in app.py/file_qa.py.
